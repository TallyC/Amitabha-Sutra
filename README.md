# 阿彌陀經（Amitabha-Sutra）

讀、誦、念佛、迴向的《佛說阿彌陀經》學習小工具。純網頁（單一 `index.html`），可加到手機桌面使用；紀錄只存在使用者自己的瀏覽器，不需帳號。

網址：https://tallyc.github.io/Amitabha-Sutra/

## 功能
- **首頁**：今日入口、累計與提醒。
- **讀經**：十五段經文，水彩圖配白話與名詞小辭典。
- **誦經**：背誦小卡（短／中／長／自訂字數）、語音報讀、整部經文。
- **念佛迴向**：選佛珠、撥珠計數（珠數可設，最多 36）、定時與專注時段；念過才出現迴向與祝福卡。
- **深入**：淨土宗與十三祖簡介；每段的聖嚴法師、蕅益《要解》、蓮池《疏鈔》三家說法（皆附原文出處連結）；兩家並排看；兩個譯本並排（羅什本與玄奘本）；信願行小記錄；書目。
- **設定**：字體、行距、分段、背誦字數、語音、**帶走／接回進度**（備份檔或備份碼，不需寄信）。

## 經文與資料
- 經文：姚秦鳩摩羅什譯，取自 CBETA T12n0366。
- 古德與法師的說法為白話改寫，逐段對照原書後才放入，並附 CBETA／法鼓全集連結；AI 協助撰寫，請以原典與師長開示為準。
- 「準備中」的區塊（一心不亂、六方諸佛地圖、梵漢小對照）尚未逐字核對，核完才開放。

## 推出前
```
python3 check.py                       # 檢查每段 script 語法（需要 node）；有錯就不要推
python3 ver.py minor "這一版改了什麼"   # 改版號並寫入版本記錄（big／minor／micro）
```
版號 `V-主.小微`：主＝大修、小＝小修、微＝微調。

## 檔案
- `index.html`：整個工具（含內嵌圖片）。
- `assets/`：底圖與讀經插圖；`logo/`、`icons/`：標誌與 App 圖示。
- `sw.js`、`manifest.webmanifest`：安裝到桌面與離線快取（網路優先）。
- `data/`：經文分段與名詞資料的整理來源。
